[简体中文](README.md) · **English**

## Quick start

1. Run the Windows installer, then open Format Converter.
2. Drop files or folders into the window, or click **Add Files**.
3. Pick a category and format under **② Target format**, then click **Start**. The app saves files in date-based folders under `格式转换输出` in your user directory by default. Change the location under **Settings → General**.
4. Choose Simplified Chinese or English on first launch. To switch later, click **EN / 中文** in the title bar. The app saves your choice automatically.

## Features

- Convert formats such as PNG, JPEG, WEBP, GIF, ICO, TIFF, HEIC, AVIF, PDF, DOCX, ODT, RTF, SVG, AI, EPS, and WMF in batches.
- Convert videos to MP4, MOV, MKV, WEBM, AVI, WMV, FLV, TS, MTS, M2TS, MPG, MPEG, 3GP, and VOB. Choose H.264, H.265/HEVC, AV1, VP9, VP8, ProRes 422 HQ, DNxHR HQ, MPEG-2, or MJPEG, or keep the original codec to remux the video. If a codec is incompatible with the container, the app uses the recommended codec and reports the change in the result.
- Save conversion presets, including video codec and maximum dimension. Use the Tasks and History pages to check progress and results.
- Drop files or folders on the floating ball to choose from up to six quick formats. It can dock to a screen edge and stay available in the background. Right-click it to open the main window, settings, or output folder, or to quit.
- Memos: a section separate from conversion to create, search, pin and rename notes, saved automatically. Paste, drop or insert images and resize them by dragging. The always-on-top desktop sticky window shows up to 3 notes of your choice stacked downward, each collapsible; double-click a name to rename it. It stays in sync with the main window.
- The left sidebar has a Converter group and a Memos group, and can collapse to icons only.
- Switch between light and dark modes and customize the background tint and accent color.

## Works with Download Butler (optional)

[Download Butler](https://github.com/RonganBai/Download-File-Manager) ([get the installer](https://github.com/RonganBai/Download-File-Manager/releases/latest)) is a separate small tool that sorts your Downloads folder by type and cleans up old files. Either app works on its own; with both installed they link up automatically:

- In Download Butler, right-click files → “转换为” (Convert to) lists the same quick formats as the floating ball. One click converts them in the background; a tray notification opens the output folder.
- “更多格式…” (More formats) adds the files to Format Converter's main list instead.

Other programs can call it the same way (if Format Converter is already running, the running copy takes the job — no second instance):

```powershell
FormatConverter.exe --to PNG --from MyTool a.heic b.webp
```

`--to` accepts `PNG`, `image:PNG` or `preset:<preset id>`; without `--to` the files are just added to the list. The program path, quick formats and supported extensions are in `%APPDATA%\格式转换器\integration.json`.

## Run from source

Requires Windows 10/11 and Python 3.10 or later.

```powershell
python -m pip install -r requirements.txt
python app.py
```

## Build the installer

Install Inno Setup 6 and run this in PowerShell:

```powershell
.\build.ps1
```

PyInstaller bundles the app, and Inno Setup writes the installer to `installer/Output/`. DJVU requires DjVuLibre. JBG requires JBIG-KIT's `pbmtojbg.exe` on PATH.
